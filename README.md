# ⏰ YouTube Alarm Clock

¡Despierta con ritmo! Este es un script de Python sencillo y eficaz que funciona como un despertador personalizado, abriendo una canción aleatoria de YouTube a la hora que tú decidas.

---

## 🚀 Características
* **Selección Aleatoria:** Elige una URL al azar de tu lista para que no te canses siempre de la misma canción.
* **Fácil Configuración:** Solo necesitas un archivo de texto con tus enlaces.
* **Ligero:** No requiere librerías externas; utiliza módulos nativos de Python.

## 📋 Requisitos
Antes de empezar, asegúrate de tener:
1. **Python 3.x** instalado en tu sistema.
2. Un **navegador web** configurado como predeterminado (Chrome, Firefox, Edge, etc.).

## 🛠️ Instalación y Configuración

1. **Clona este repositorio** o descarga el archivo `.py`.
2. **Crea el archivo de música:** En la misma carpeta del script, crea un archivo llamado `youtube_urls.txt`.
3. **Añade tus canciones:** Pega las URLs de YouTube que quieras, **una por cada línea**. Por ejemplo:
   ```text
   [https://www.youtube.com/watch?v=dQw4w9WgXcQ](https://www.youtube.com/watch?v=dQw4w9WgXcQ)
   [https://www.youtube.com/watch?v=ASO_zypdnsQ](https://www.youtube.com/watch?v=ASO_zypdnsQ)
